Overview

Purpose

The purpose of this website is to help players create a first-level Dungeons & Dragons 5.5e character through a guided, step-by-step character creation process. Users will select a class, species, background, and assign ability scores generated using the official 4d6-drop-lowest method. The completed character summary will display the selected class, species, background, traits, proficiencies, origin feat, class features, ability scores, and ability modifiers.

Audience

This website is intended for new and experienced Dungeons & Dragons players who want an easy-to-use character creation tool. It is especially useful for players creating a first-level character who want a guided process instead of searching through multiple reference sources while building their character.

Dynamic elements

The website will use JavaScript to load character data from a JSON file and dynamically generate the available classes, species, and backgrounds. Users will make selections that are stored throughout the character creation process. JavaScript will roll four six-sided dice, remove the lowest roll, total the remaining three dice, calculate ability modifiers, respond to user interactions, update the page using DOM manipulation, save progress with Local Storage, and generate a final character summary page.

Pseudocode for your project

START

Load the JSON database.

Display the landing page.

If the user begins character creation:
  Display all available classes.
  Save the selected class.

  Display all available species.
  If the selected species requires an additional choice, display the available options and save the selection.

  Display all available backgrounds.
  Save the selected background.

  Repeat six times:
    Roll four six-sided dice.
    Remove the lowest die.
    Add the remaining three dice.
    Allow the user to assign the score to an unused ability.

Calculate all ability modifiers.

Store the completed character using Local Storage.

Display a summary page showing the completed character and all selected information.

END

Wireframes

Wireframes will be created for each page before implementation. The website will use a consistent header, navigation menu, and logo across all pages.

Landing page

The landing page will introduce the project, display the website logo, provide navigation links, explain the purpose of the application, and include a button to begin creating a character.

Character Creation Pages

Separate pages will allow the user to select a class, species, background, and assign ability scores before displaying the final character summary.
